# Мандариновый Комплекс — Ивент-отделы

Справочник Medium RP и NoRules / Classic с мандариновым оформлением. Материалы редактируются в исходниках; формы добавления на сайте нет.

Сервер доступа переведён на Google: подтверждённый аккаунт → разрешённая почта или одобренная заявка → справочник. ID сервера, роли и бот Discord не нужны. Членство в проекте проверяется вручную.

На 24.09.2026 текущий сайт в Sites закрыт штатным доступом ChatGPT для владельца. Страница `login.html` показывает новое оформление входа с мандаринами и снегом. Google-вход и панель подготовлены для отдельного серверного размещения, но ещё не подключены к реальному Google-приложению. Действующих секретов в архиве нет.

**Разместить по шагам:** [DEPLOY_RENDER.md](DEPLOY_RENDER.md). **Как управлять:** [ADMIN_GUIDE.md](ADMIN_GUIDE.md). **Настройки сервера:** [SECURE_SETUP.md](SECURE_SETUP.md).

В шаблонах уже указана почта владельца `liryzliryz34@gmail.com`. Файл `render.yaml` готовит один Node.js-сервис с постоянным диском. Хостинг и настоящее Google-приложение ещё нужно подключить в своих аккаунтах; конфигурация сама ничего не покупает.

## Запуск

Для защищённой версии нужны Node.js 24.19+, официальная библиотека Google и настройки из [SECURE_SETUP.md](SECURE_SETUP.md).

    npm ci --omit=dev --ignore-scripts
    cp .env.example .env
    # Заполните .env по инструкции, затем:
    npm start

Локальный адрес по умолчанию: http://127.0.0.1:8787. Без заполненных настроек сервер показывает закрытый вход и не выдаёт материалы.

`dist/index.html` можно открыть локально для просмотра оформления. Папка `dist` сама по себе содержит весь справочник без защиты. Не публикуйте её на открытом статическом хостинге: авторизация выполняется сервером, а не JavaScript в браузере.

## Возможности

- Стартовый выбор отдела и переключатель в шапке.
- Отдельные каталоги NR и Classic с выбором сервера.
- Фильтр ивентов по должности и типу; допуски учитывают иерархию, временные ограничения и правила сервера.
- Поиск в выбранном отделе; ссылки на конкретные карточки сохраняют отдел.
- Регламент, команды, копирование в буфер; C.A.S.S.I.E. для MRP.
- Мандариновое оформление с лабораторной иллюстрацией.
- Плотный снег с разным размером и скоростью снежинок, с выключателем. Выбор сохраняется только в этом браузере. Анимация приостанавливается в фоновой вкладке; системное уменьшение движения учитывается.
- В отдельной серверной версии: вход Google, разрешённые почты, заявки, панель владельца `/admin`, поиск по почте, журнал за 30 дней и отзыв всех сессий сотрудника.

Старые адреса вида #events/scp-131 продолжают открывать MRP.
Новые адреса: #mrp/home, #nr/events?role=junior, #classic/events.

Данные статические. Автоматической синхронизации с Google Документами нет.
Для новых карточек нужны уникальные id. Поле rank принимает junior, master, senior или lead.

Фильтр выбранной должности исключает такие записи и disabled-карточки.

Если источник содержит противоречивые параметры, карточка указывает на расхождение. Доступ к оригинальным Google Документам зависит от настроек их владельцев: вход на сайт не изменяет права на исходные документы.

## Размещение

Защищённую версию размещайте по [SECURE_SETUP.md](SECURE_SETUP.md): один Node.js-процесс, HTTPS и постоянный диск для базы доступа. Все HTTP-запросы должны попадать в `server/start.mjs`. Раздача `dist` отдельным публичным каталогом обходит защиту.

Настройки `.openai/hosting.json` относятся только к существующему статическому сайту в Sites, где временная защита — штатный вход ChatGPT. Они не запускают Node.js-сервер и не включают Google OAuth.

Адреса разделов используют #, дополнительные серверные перенаправления не требуются.

Проверки сервера: `npm test`. Они используют тестовые Google-ответы и локально подписанные токены без сетевого доступа. Реальный OAuth-проход проверяется после подключения приложения. Обновление статического предпросмотра: `npm run preview:login`.

Тексты и названия сценариев: Mandarin, 2025–2026 и авторы, указанные в источниках.
Иллюстрация создана для этого оформления. Скриншоты переписки на сайт не добавлены.

Оформление обновлено 24.09.2026: мягкий графит, тёплые оранжевые акценты, мандарины с листьями и более заметный снег.
