## Локальный просмотр

Для серверной версии и админки следуйте `DEPLOY.md`; запуск — `npm run owner`, затем `npm start`. Дополнительных npm-зависимостей нет, нужен Node.js 24.19+.

Откройте `dist/index.html` в браузере. Сборка и установка пакетов не нужны. Для просмотра через локальный сервер можно выполнить из каталога проекта:

```sh
python3 -m http.server 8000 --directory dist --bind 127.0.0.1
```

## Обновление 1.12

Метки быстрой панели Кэсси перенесены непосредственно из нативных вкладок документа: пять цветных кругов соответствуют МОГ, ПХ, общему НОУС, НОУС и ВОУС; исходные значки остальных категорий сохранены. Выбранная цветная вкладка сохраняет свой оттенок и получает дополнительную границу. Подписи остаются видимыми, поэтому навигация не зависит от различения цветов. Снежные края и осыпающийся снег добавлены к быстрым вкладкам, вариантам и кнопке доступа с учётом общего выключателя и уменьшения движения. Команды и тексты не менялись.

В шапке появился вход в окно доступа. В серверной версии оно показывает пользователей, роли, разрешённые и закрытые допуски, форму добавления и журнал. Учётные записи и изменения сохраняются в SQLite. На каждый запрос проверяются серверная сессия и текущий статус; защищены все файлы материалов, а не только главная страница. Для записи проверяются роль, исходящий адрес запроса и CSRF-токен. Пароли хешируются с индивидуальной солью scrypt; сессии хранятся по хешу токена. Временный пароль выдаётся один раз, действует семь дней и меняется до открытия материалов. Блокировка, сброс пароля и смена роли завершают сессии. Владелец защищён от изменения допуска через панель.

Админка предназначена для Node.js-хостинга и устанавливается по `DEPLOY.md`. Статическая публикация ChatGPT Sites сохраняет собственный механизм допуска; её окно прямо объясняет, что разрешения платформы изменяются в настройках публикации. Парольная админка не выдаёт доступа к публикации Sites и не меняет текущую аудиторию.

Добавлена краткая помощь для новичков с расшифровкой НОУС, ВОУС, МОГ и ПХ. Исходные статусы и доступность команд сохранены. В общем НОУС обнаружено противоречие внутри оригинала: карточка `cassie-0255` озаглавлена «НОУС 6 Кетер & Евклид», но подраздел и текст команды указывают 7 объектов. В быстром выборе показано «7 объектов» по подразделу и команде; исходное название сохранено в полном просмотре вместе с пояснением. Данные и копируемые строки не изменены.
